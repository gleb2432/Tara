# План реализации: Превращение в полноценное PWA-приложение для Android

## Описание
PWA (Progressive Web App) позволяет установить веб-терминал прямо на смартфон Android как полноценное автономное приложение:
- Появляется отдельная иконка «Терминал Стеклотары» на рабочем столе и в списке приложений Android.
- Запускается в собственном отдельном окне без браузерной строки (standalone mode).
- Работает быстро и поддерживает офлайн-кеширование.

## Шаги реализации

### 1. Установка и настройка PWA (`vite-plugin-pwa`)
- Установить пакет `vite-plugin-pwa` в `devDependencies`.
- Настроить `vite.config.ts` с манифестом приложения:
  - `name`: "Терминал стеклотары"
  - `short_name`: "Терминал"
  - `display`: "standalone"
  - `background_color`: "#020617" (slate-950)
  - `theme_color`: "#020617"

### 2. Создание иконок приложения
- Создать PNG иконки для смартфона:
  - `/pwa-192x192.png` (для домашнего экрана Android)
  - `/pwa-512x512.png` (для заставки и маркета)
  - `/apple-touch-icon.png` (для устройств iOS)

### 3. Кнопка «Установить приложение» в шапке
- Создать React-хук `usePWAInstall.ts` для перехвата события установки `beforeinstallprompt`.
- Добавить яркую кнопку «Установить приложение» в шапку терминала (`src/components/Header.tsx`), которая открывает системный диалог установки Android в 1 клик.

### 4. Проверка и сборка
- Проверить компиляцию через `compile_applet` и `lint_applet`.
